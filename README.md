# 금융 브리핑 룸

매일 아침 텔레그램으로 금융 뉴스 브리핑을 받고, 그 뉴스가 웹사이트에 **테마별로 쌓이는** 구조입니다.
목적은 두 가지 — 받아본 뉴스를 다시 떠올리기 쉽게 만들기, 그리고 큰 흐름(트렌드) 파악하기.

**사이트:** https://pkr010917.github.io/finance-briefing-room/

## 어떻게 돌아가나

평일 아침 7시(KST), GitHub Actions가 자동 실행합니다. 컴퓨터가 꺼져 있어도 됩니다.

```
RSS 5곳에서 뉴스 수집  →  Claude가 브리핑 작성  →  텔레그램 발송
                                                      ↓
                                          기사를 테마별로 축적
                                                      ↓
                                          웹사이트 자동 갱신
```

1. **뉴스 수집** — 한국경제(금융·경제), 연합뉴스 경제, 연합인포맥스, 머니투데이의 RSS에서
   최근 36시간 기사를 모읍니다. 파이썬 표준 라이브러리만 쓰므로 **API 비용 0원**.
2. **브리핑 작성·발송** — 수집된 기사 중 상위 70건을 Claude가 읽고 4개 섹션으로 씁니다.
   채용 공고는 RSS에 잘 안 잡혀서 이 섹션만 웹 검색을 씁니다.
   - 1️⃣ 주요 시중은행 동향 · 2️⃣ 금융 정책·규제 · 3️⃣ 채용·취업 · 4️⃣ 오늘의 면접포인트
   - 서식은 매일 동일합니다 — 요약 → 섹션 4개, 기사마다 `제목 → 사실 → 💡 의미` 순.
   - 3️⃣ 채용은 `data/jobs.json` 대장으로 관리합니다. 새 공고만 검색하고, 이미 찾은 공고는
     은행/금융공기업/증권/기타로 묶어 D-day와 함께 계속 보여주다 마감일에 자동으로 사라집니다.
3. **축적** — 다룬 기사를 9개 거시 트렌드 중 하나로 분류해 `data/trends.json`에 쌓습니다.
   어디에도 안 맞는 기사는 따로 모아두었다가, 충분히 쌓이면 새 트렌드로 승격됩니다.

## 웹사이트 화면

- **최신 브리핑 보드** — 그날 받은 뉴스가 테마별 카드로 정리됩니다. 기사 제목이 그대로 보여서
  "그 기사가 이 흐름이었지"를 클릭 없이 바로 확인할 수 있습니다.
- **모든 트렌드** — 추적 중인 9개 흐름을 최근 활동순으로. 이름을 누르면 설명과 축적된 뉴스 전체.

## 뉴스 선정 기준

독자가 금융권 취업 준비생이라는 전제로 우선순위를 매깁니다.

1. 한국 은행·금융지주·금융당국의 **구조적 변화** (규제·감독방향·수익구조·M&A)
2. 추적 중인 거시 트렌드와 직접 연결되는 뉴스
3. 한국은행·금융위·금감원의 결정과 파급
4. 개별 금융사 소식 중 업계 전체에 시사점이 있는 것

개별 종목 시황, 한국 금융권과 무관한 해외 뉴스, 홍보성 보도자료는 후순위입니다.
