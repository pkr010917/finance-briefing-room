# finance-briefing-room

한국 금융업의 거시 트렌드를 블룸버그 터미널 스타일로 보여주는 웹사이트 + 텔레그램 데일리 뉴스레터 봇.

- 평일 아침 7시(KST), GitHub Actions가 자동으로:
  1. Claude가 금융 뉴스를 리서치해 **텔레그램 뉴스레터** 발송
  2. 리서치한 기사를 거시 트렌드별로 분류해 `data/trends.json`에 **축적**
  3. 네이버 뉴스를 반영해 트렌드 설명(개요·주목할 점) 갱신
- 웹사이트(GitHub Pages)는 `data/trends.json`을 읽어 트렌드 블록과 관련 기사 아카이브를 표시

설정 방법은 [자동화-설정-가이드.md](자동화-설정-가이드.md) 참고.
