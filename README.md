# finance-briefing-room

매일 아침 텔레그램으로 받는 금융 데일리 브리핑의 뉴스가, 웹사이트에서 트렌드 그래프로 쌓입니다.
받아본 뉴스를 다시 떠올리기 쉽게 만들고, 트렌드를 파악하는 것이 목적입니다.

- 평일 아침 7시(KST), GitHub Actions가 자동으로:
  1. Claude가 금융 뉴스를 리서치해 **텔레그램 뉴스레터** 발송
  2. 리서치한 기사를 거시 트렌드별로 `data/trends.json`에 **축적**
  3. 미분류 기사가 충분히 쌓이면 **새 트렌드(카테고리) 발굴**
- 웹사이트(GitHub Pages)는 트렌드를 원으로, 뉴스를 그 주위의 점으로 보여줍니다.
  오늘 새로 연결된 뉴스는 초록색이고, 지난 7일간 가장 활발한 트렌드에는 배광이 들어옵니다.

설정 방법은 [자동화-설정-가이드.md](자동화-설정-가이드.md) 참고.
